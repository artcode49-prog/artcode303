ACID-303 — TB-303 エミュレーション VST3
========================================
バージョン 1.0.0  /  ライセンス: GNU AGPL v3.0 またはそれ以降 (LICENSE を参照)

このフォルダは配布用の一式です。
macOS は同じ内容のディスクイメージ（Acid303-1.0.0-macOS.dmg）でも配布しており、
そちらは開いてドラッグするだけです。

■ インストール

  macOS（Universal: Apple Silicon / Intel 両対応）

    .dmg を使う場合（おすすめ）
      1. Acid303-1.0.0-macOS.dmg をダブルクリックして開きます
      2. 中の Acid303.vst3 を次のフォルダへドラッグします
           ~/Library/Audio/Plug-Ins/VST3/
         （Finder の「移動 > フォルダへ移動...」に上のパスを貼り付けると簡単です）
      3. DAW を起動してプラグインをスキャンさせます（多くは自動で認識します）

    zip を使う場合
      1. zip を展開し、中の Acid303.vst3 を同じフォルダへコピーします
      2. DAW を起動してプラグインをスキャンさせます

    警告が出た場合は「macOS でブロックされたとき」を参照してください。

  Windows（64bit）
    1. Acid303.vst3 を次のフォルダへコピーします
         C:\Program Files\Common Files\VST3\
    2. DAW を起動してプラグインをスキャンさせます

■ はじめかた

  - クロック源は既定で HOST です。DAW を再生するとシーケンサーが鳴ります。
  - DAW を使わず単体で鳴らすには CLOCK を INT に切り替えて PLAY を押します。
  - PLAY ボタンは Host モードでも停止ボタンとして使えます。
    もう一度押すと再開します（DAW を停止 -> 再生し直しても自動で再開）。
  - 中央の 16 ステップグリッドで NOTE / OCT / ACC / SLD / REST を編集できます。

■ macOS でブロックされたとき（Gatekeeper）

  このビルドは Apple の Developer ID で署名しています（公証済みのビルドでは
  通常この警告は出ません）。それでも「開発元を確認できません」「壊れている
  ため開けません」と表示される場合は、ダウンロード時に付いた「隔離属性」が
  原因です。ターミナルで次を実行してください:

    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Acid303.vst3

  （実際に置いた場所に合わせてパスを変えてください）
  実行後、DAW を再起動してプラグインを読み込み直します。

■ Windows でブロックされたとき（SmartScreen）

  「Windows によって PC が保護されました」と表示された場合は
  「詳細情報」→「実行」を選んでください。ZIP を展開する前に、ファイルを
  右クリック → プロパティ → 下部の「ブロックの解除」にチェックを入れておくと
  確実です。
